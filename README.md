# MatchSignal

A compact football prediction dashboard built from direct home-versus-away history.

The current page shows recent direct meetings, result likelihoods, and goal-threshold likelihoods. Prediction cards use up to five recent direct fixtures from a three-season window.

## Current version

`index.html` is a static snapshot that can be hosted on Render or GitHub Pages. The data-refresh and database service can be added as the next deployment step.
