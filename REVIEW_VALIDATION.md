## Remaining acceptance gates

**Visual mobile/desktop validation is blocked, not passed.** Local Chromium installation failed because the browser download was invalid. The supported cloud browser could not reach the local app and disallowed local-file navigation. No attempt was made to circumvent that policy. Responsive CSS and rendered content have been inspected/tested, but actual viewport layout, clicking day controls and real iPhone Safari behaviour require a reachable preview.

**Production is not deployed.** Changes are prepared on a separate branch for review. Render's existing entry point is preserved, but live account environment configuration was not accessible. Merge/deploy and verify the first production refresh before treating the rewrite as fully accepted.

## Operational limitations

- Sky is currently the only verified live table integration. Table outages fall back to last-good data for at most 12 hours; expired data is withheld. FWP fixture fallback and the existing partial SportsDB integration remain available, but neither can guarantee recovery from every Sky outage.
- Daily fixture pages validate the existing all-competition feed; they cannot prove the publisher has not omitted an individual fixture. Some supported leagues have no scheduled games within this particular five-day window; no fixtures are invented to demonstrate coverage.
- Download time and publisher update labels are separate. A source can publish stale information despite HTTP success. Per-league diagnostics expose the actual table update label.
- Scottish split order is retained from published positions; no re-ranking by points. A source that resets positions to 1 within each split group will fail validation rather than produce overlapping/incorrect groups.
